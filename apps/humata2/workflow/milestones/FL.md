- Design notes:
  - New package `clients/live` (`humata2_clients_live`, visible to `desktop` and its own tests). `LiveDaemon` implements the existing `Daemon` and `Terminals` traits over the host socket with humatad's generated tonic clients (`//apps/humata2/daemon/humatad:grpc`). It covers what This Mac's daemon serves today: `load` (GetServerInfo + ListChannels + ListSessions, mapped to `model`), `events` (EventService.Subscribe for sessions, channels, machines; Resync; plus `TerminalData` from its attaches), `create_channel` (CreateChannel, waits for the setup operation), `create_session` (StartSession with the options' repos and first message), `resume` (ResumeSession), `send` (TerminalService.Type), and `Terminals` (ListTabs/OpenShellTab, one Attach per open tab: input, resize, output as `Event::TerminalData`). Every other call answers `DaemonError::Refused` saying it comes in a later release. Agents map by name through `LiveOptions` (tests map Claude to the test agent). Its own connect errors are a thiserror enum with sources; trait methods map to `DaemonError` (Clone, no sources) with actionable text.
