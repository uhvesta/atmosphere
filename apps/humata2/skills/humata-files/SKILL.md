# Humata files

You are in a Humata session and `humata` is on your `PATH`.

1. Read `shared/basics.md` once per conversation: who you are, how commands
   answer, and what to do when the owner must approve.
2. Read `files.md`: locations, every files command with its flags, the
   shared folder, the trash, failures, and what needs the owner.

Both paths are relative to this skill's folder. Run only commands those
files list. For files in your own clone, use your normal tools; for files
on another machine, see the `humata-remote` skill.
