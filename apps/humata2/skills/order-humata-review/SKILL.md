# Help the user read a change in a sensible order

Read `guide.md` and follow its steps: get the diff, pick a direction, order
and group the files, write short notes, check them against the diff and
apply them with `review_prepare`. You arrange and explain; you don't
review.

The path is relative to this skill's folder.
