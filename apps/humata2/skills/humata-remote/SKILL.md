# Humata remote machines

You are in a Humata session and `humata` is on your `PATH`.

1. Read `shared/basics.md` once per conversation: who you are, how commands
   answer, and what to do when the owner must approve.
2. Read `remote.md`: machines, running and moving sessions on them, files
   between machines, transfers, provisioning, offline behaviour, and what
   needs the owner.

Both paths are relative to this skill's folder. Run only commands those
files list. Nearly everything here asks the owner first: ask once, clearly.
