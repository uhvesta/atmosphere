# Bundled fonts

`Inter-Regular.ttf` is the unmodified static Regular font from the official
[Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), archive
path `extras/ttf/Inter-Regular.ttf`. Its actual font family is `Inter`, matching
the UI's requested family. `LICENSE-Inter.txt` is copied unchanged from that
archive.

- Archive URL:
  `https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip`
- Archive SHA-256:
  `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`
- Font SHA-256:
  `40d692fce188e4471e2b3cba937be967878f631ad3ebbbdcd587687c7ebe0c82`

`JetBrainsMono-Regular.ttf` and its license are shared from the existing
prototype assets. Its actual font family is `JetBrains Mono`, matching the
terminal theme.
